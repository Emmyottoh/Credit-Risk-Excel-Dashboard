# Enterprise Credit Risk & Borrower Default Analytics Suite

## Project Overview
Financial executives and credit risk managers require granular visibility into portfolio risk profiles to minimize loan defaults and optimize capital allocation[cite: 2]. This project provides an interactive credit risk analytics suite evaluating applicant profiles, debt-to-income (DTI) metrics, loan status distributions, and borrower demographics to identify high-risk indicators and strengthen underwriting decision-making[cite: 2].

## Technical Stack & Tools
* **Data Analytics & Visualization:** Tableau Cloud / Power BI Desktop, Dynamic Filters, Parameter Controls[cite: 2]
* **Data Engineering & ETL:** SQL, Power Query, Data Cleaning, Normalization, Quality Auditing[cite: 1, 2]
* **Spreadsheets & Modeling:** Microsoft Excel, Dynamic Formulas, Financial Risk Modeling[cite: 2]
* **Core Competencies:** Analytical Skills, Statistics, Data Modeling, Credit Risk Profiling, Executive Communication[cite: 2]

## Key Features & Business Impact
* **Risk Exposure Profiling:** Modeled default distributions and debt-to-income (DTI) tiers to isolate high-risk applicant profiles using advanced **Analytical Skills**[cite: 2].
* **Statistical Stress-Testing:** Applied **Statistics** and parameter controls to enable credit officers to evaluate default sensitivity across employment duration and credit grade groupings[cite: 2].
* **Data Modeling & Architecture:** Constructed structured relational schemas connecting borrower financials, loan terms, and repayment histories[cite: 2].
* **Executive Decision Support:** Designed intuitive KPI tracking layouts to communicate risk exposure, non-performing assets, and recovery metrics clearly to non-technical stakeholders[cite: 2].

## Data Pipeline & Methodology
1. **ETL & Ingestion:** Processed raw applicant records using **SQL** and **Power Query** to handle null values, remove duplicates, and normalize financial fields[cite: 1, 2].
2. **Exploratory Data Analysis:** Leveraged **Microsoft Excel** and **Python** to inspect metric distributions and calculate baseline default probabilities[cite: 1, 2].
3. **Dashboard Construction:** Built interactive views with cross-filtering capabilities and parameter-driven scenario modeling[cite: 2].
